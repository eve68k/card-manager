# 名刺管理

## 解決したいこと

各種技術イベントに参加していると名刺交換やSNSのアカウントをフォローすることがある

しかし、イベントでしか顔を合わせない関係の場合や、もしくは「いつなんの用事でフォローしたっけ・・・」と名刺やアカウントを見てどういう人なのか思い出せないことがある

そこで、名刺やSNSアカウントをイベントや特徴と紐づけて管理することで、どういう人だったかを思い出せるようにする

## 動作環境

スマートフォンでの利用を前提とした画面設計とする

デスクトップ環境でも利用できるが、スマートフォンファーストとすることでレスポンシビリティへの対応を容易にする

## 技術

Voidフレームワークを利用しCloudflare上にデプロイする
